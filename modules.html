🧩 Модульная документация

Структура и описание всех модулей веб-сайта «Le Bistro Noir».

📦 Модуль 1: Авторизация и регистрация (auth)

Файл: script.js (функции register, login, logout)

Назначение: Управление пользовательскими сессиями, регистрация новых пользователей, вход в аккаунт.

Зависимости: JSONBin API (users_bin)

Интерфейс: register(name, email, phone, password), login(email, password)

📦 Модуль 2: Управление бронированиями (booking)

Файл: script.js (функция addBooking)

Назначение: Создание, хранение и отображение бронирований столиков.

Зависимости: JSONBin API (bookings_bin), модуль авторизации

Интерфейс: addBooking(userId, name, phone, date, time, guests)

📦 Модуль 3: Отображение меню (menu)

Файл: script.js (функции renderMenu, фильтрация)

Назначение: Рендеринг списка блюд с категориями и картинками.

Данные: Локальный массив menuData (12 блюд)

Интерфейс: renderMenu(filter)

📦 Модуль 4: Админ-панель (admin)

Файл: admin.html

Назначение: Управление пользователями (блокировка/удаление) и бронированиями (удаление).

Зависимости: JSONBin API (users_bin, bookings_bin)

Интерфейс: toggleBlockUser, deleteUser, deleteBooking

📦 Модуль 5: Работа с JSONBin (jsonbin-client)

Файл: script.js, admin.html

Назначение: CRUD-операции с облачным хранилищем.

// Чтение данных async function fetchBin(binId) { ... } // Запись данных async function updateBin(binId, data) { ... }

📦 Модуль 6: UI-компоненты (ui)

Файл: script.js, style.css

Назначение: Нижняя навигация, переключение страниц, модальные окна, формы.

Компоненты: bottom-nav, modal, формы логина/регистрации, фильтры меню.

📦 Модуль 7: Валидация данных (validation)

Файл: script.js

Функции: validatePhone (строго 11 цифр), проверка длины имени и пароля.

Архитектура приложения

Сайт построен по принципу SPA (Single Page Application) с подгрузкой данных из JSONBin. Все пользовательские данные хранятся в облаке, состояние сессии — в localStorage.

Структура данных JSONBin: // users_bin { "users": [ { "id": 123, "name": "...", "email": "...", "phone": "...", "password": "...", "blocked": false } ] } // bookings_bin { "bookings": [ { "id": 456, "userId": 123, "name": "...", "phone": "...", "date": "...", "time": "...", "guests": 2 } ] }
