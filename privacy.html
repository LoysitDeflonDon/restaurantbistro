🔒 Политика конфиденциальности

Настоящая Политика конфиденциальности описывает, как ресторан «Le Bistro Noir» (далее — «Ресторан», «мы», «нас») собирает, использует и защищает информацию, которую вы предоставляете при использовании нашего веб-сайта.

1. Какие данные мы собираем

  • Имя и контактные данные — для идентификации гостя и связи с вами.
  • Номер телефона — для подтверждения бронирований.
  • Email — для отправки уведомлений о бронированиях.
  • История бронирований — для улучшения качества обслуживания.

2. Как мы используем данные

  • Для обработки и подтверждения бронирований.
  • Для связи с вами по вопросам обслуживания.
  • Для улучшения работы сайта и сервисов ресторана.
  • Для соблюдения юридических обязательств.

3. Хранение данных

Все данные пользователей хранятся в зашифрованном виде в облачной базе данных (JSONBin). Доступ к данным имеют только авторизованные администраторы ресторана.

4. Передача данных третьим лицам

Мы не продаём и не передаём ваши личные данные третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Ваши права

Вы имеете право запросить удаление всех ваших данных из нашей системы. Для этого обратитесь к администратору через форму бронирования или по телефону.

6. Изменения в политике

Мы оставляем право вносить изменения в данную Политику конфиденциальности. Актуальная версия всегда доступна на этой странице.
