🛠️ Документация разработчика

Техническая документация для разработчиков, поддерживающих проект «Le Bistro Noir».

1. Стек технологий

  • HTML5 — структура страниц
  • CSS3 — стилизация, адаптивный дизайн
  • JavaScript (ES6+) — вся бизнес-логика
  • JSONBin.io — облачное хранилище данных (REST API)
  • Font Awesome 6 — иконки

2. API JSONBin

Все данные пользователей и бронирований хранятся в JSONBin.

// Базовый URL https://api.jsonbin.io/v3/b/{BIN_ID}/latest // Заголовки X-Master-Key: {MASTER_KEY} Content-Type: application/json

3. Структура проекта

/ ├── index.html # Главная страница ├── admin.html # Админ-панель ├── style.css # Общие стили ├── script.js # Основная логика (frontend) └── README.md # (документация)

4. Конфигурация (переменные окружения)

В script.js: заменить на свои данные:

const MASTER_KEY = 'твой_api_ключ'; const USERS_BIN_ID = 'id_бина_с_пользователями'; const BOOKINGS_BIN_ID = 'id_бина_с_бронями';

7. Безопасность (важно!)

⚠️ Для учебного проекта пароли хранятся в открытом виде. Для реального продакшена необходимо:

  • Хешировать пароли (bcrypt)
  • Перенести MASTER_KEY на серверную часть
  • Использовать HTTPS везде
  • Добавить CSRF-защиту

8. Локальный запуск

Сайт полностью статический. Достаточно открыть index.html в браузере. Никаких серверов не требуется.
